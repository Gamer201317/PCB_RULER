# PCB_RULER
📏 PCB Ruler

A handy PCB ruler with a built-in 0°–180° degree scale, making it useful for measuring both dimensions and angles while working on PCB designs.

It also includes a collection of different PCB footprints, so you can quickly check component sizes and hole patterns. It’s also just a pretty fun little thing to have on your desk while designing PCBs. Because apparently even rulers need to be over-engineered.
